# 🪱 vetfecrt-site — ФЭКРТ-калькулятор

Публичная витрина [shray77.github.io/vetfecrt-site](https://shray77.github.io/vetfecrt-site/) —
полевой калькулятор теста снижения числа яиц гельминтов (FECRT) по гайдлайну
WAAVP-2023: редукция счёта яиц с 90% доверительным интервалом и вердиктом
«резистентность / серая зона / восприимчив». Отдельная репа-сайтик —
открывать сайт проще, чем обновлять APK.

## Что внутри

- `index.html` — витрина: лист расчёта (голос B «Формуляр») + методология
  с порогами и честными ограничениями (голос A «Периодика»).
- `fecrt.js` — математическое ядро без DOM: парная формула и формула с
  контрольной группой, перцентильный бутстрэп 90% ДИ на детерминированном
  генераторе (mulberry32, фикс. сид), классификация двумя односторонними
  тестами, род-специфичный пересчёт по культуре L3.
- `tests/fecrt.test.mjs` — гейт известных ответов: RU-запятая и мусорный
  ввод, ручная арифметика, ЗОЛОТО бутстрэп-интервалов, границы серой зоны,
  сквозной `compute()`.
- `tests/thresholds.reference.json` — референс порогов вида × препарата
  (паттерн tokens.json-verify): дрейф `THRESHOLDS` = красный CI.
- `vet-ds.css` + `fonts/` — копия ядра ДС (синкер `vet-ds/scripts/sync.py`,
  реестр адопций).

## Методика (в двух словах)

- Парный дизайн: `FECR% = 100 × (1 − среднее(после)/среднее(до))`;
  с контролем: `100 × (1 − (T2/T1)/(C2/C1))`.
- 90% ДИ — перцентильный бутстрэп, 10 000 реплик, фиксированное зерно:
  одинаковый ввод → одинаковый интервал (гейтится золотом).
- Вердикт: вся 90% ДИ ≥ E → «восприимчив»; вся 90% ДИ < M →
  «резистентность»; между — серая зона (Denwood et al. 2023 —
  статистический каркас WAAVP-2023).
- Пороги: лошади — NOAH (БЗД 95/90, пирантел 90/85, МЛ 98/95);
  мелкие жвачные — классика WAAVP + операционализация-2024 (95/90);
  КРС — адаптация классики (95/90, без валидации против убойных
  исследований). Источники и интервалы проб — в справке витрины.

## Гейты

```
node --test tests/fecrt.test.mjs   # известные ответы + золото бутстрэпа + verify порогов
```

CI (`.github/workflows/ci.yml`) гоняет то же на каждый пуш. Дизайн —
через общие гейты vet-ds (`contrast_v2.py`, `a11y_gate.py`,
`character_gate.py`, `codegen.py --verify`, реестр `sync.py`).

## Приватность

Считает в браузере, ничего не отправляет; работает с диска (file://)
и офлайн после первой загрузки.

## Дисклеймер

Полевой скрининг, не эталонный метод; не заменяет заключение
паразитолога и лабораторию. Вердикт — о стаде, не об отдельном животном.
